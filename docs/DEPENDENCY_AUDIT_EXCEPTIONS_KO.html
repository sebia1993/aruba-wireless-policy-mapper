Netmiko 4.8.0의 기본 의존성은 Paramiko 5.0.0과 호환됩니다. [Netmiko 4.8.0 배포 메타데이터](https://pypi.org/pypi/netmiko/4.8.0/json)

앱은 장비 인증 전에 서버 키를 앱 전용 known_hosts와 비교합니다. 미승인 키와 변경된 키는 연결을 차단합니다. RSA 장비 키를 사용할 때는 장비가 RSA-SHA2 서명을 지원해야 합니다. SSH 실패 시 Telnet으로 자동 전환하지 않습니다.
